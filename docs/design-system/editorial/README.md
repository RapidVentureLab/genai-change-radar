# RVL Editorial System — Swiss Newsroom Edition

Use this system for reading-first RVL products: intelligence radars, research briefings, market reports, editorial knowledge bases and public insight products.

## Files
- `SPEC.md` — normative design specification and research basis
- `tokens.css` — portable tokens
- `PROMPT.md` — prompt-ready implementation brief
- `QA_CHECKLIST.md` — mandatory pre-publish checks

## When to use which RVL system
- **RVL Bento**: decision tools, dashboards, calculators, operational workbenches.
- **RVL Editorial**: reading, research, intelligence, narrative evidence, archives.

They share the RVL brand, Instrument Sans, JetBrains Mono, green accent family and 4px spacing logic. RVL Editorial adds Newsreader and replaces tile-first composition with grid/rule/story composition.
